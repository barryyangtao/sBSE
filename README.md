# sBSE
A complete set of stage-wise source codes and an example cy7 monomer stochastic Bethe-Salpeter Equation (sBSE) run.

- Only one additional package is needed: LIBXC_5.2.3.

- A general tutorial demonstrating compilation and execution of the code is available here: https://www.youtube.com/watch?v=AOwg3HVnT04
